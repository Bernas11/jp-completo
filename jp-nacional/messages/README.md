# Ficheiros de tradução

`pt.json` é a língua-fonte, com conteúdo real e revisto.

Todos os outros ficheiros desta pasta nasceram como cópia exata do `pt.json`
— ou seja, o site funciona e mostra-se corretamente em qualquer uma das 24
línguas desde já, mas 23 delas estão a mostrar português até serem
traduzidas a sério. Basta substituir o conteúdo de um ficheiro (mantendo as
mesmas chaves) para essa língua passar a mostrar a tradução real — não é
preciso tocar em nenhum código.
